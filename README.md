# Spyderco 2.0 Roadmap

A design timeline for the Spyderco 2.0 store in two week sprints, from MVP pages in October 2026 through Black Friday to all design approved on 3 March 2027, with a day by day calendar for each sprint.

Live: https://oliveira-teixeira.github.io/design-spyderco-2-roadmap/

## Stack

- Plain HTML, CSS and JavaScript in a single page
- Google Fonts: Fredoka, Nunito, Geist Mono
- Light and dark themes through `prefers-color-scheme`
- Inline SVG mascot

Exported from a claude.ai artifact on 9 Oct 2026.
